# The Yellow Works — Project Overview

Status: Phase 0 (Discovery). Last updated 2026-11-23.

## What this is
A creative digital growth studio for small local businesses in India (INR pricing, English only). Tagline: "Good businesses deserve to be seen."
Positioning: "We design digital experiences that get local businesses noticed, trusted and chosen."

## Three stages
1. **Agency** (now): sell websites and related services. Goal: customers and revenue.
2. **Reusable website platform** (Phase 5): shared components + industry configs, built from real demo experience.
3. **CRM + AI automation** (Phases 6–9): clinics first, then gyms and real estate.

First product: The Yellow Works' own promotional website. It is the portfolio piece prospects judge us by.
