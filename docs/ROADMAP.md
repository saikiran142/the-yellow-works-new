# Roadmap

Rule: one phase at a time; each ends with a completion report and waits for approval.

| Phase | Objective | Key outputs | Exit gate |
|---|---|---|---|
| 0 Discovery | Understand repo, business, direction | 8 docs, decisions list, risks | **Awaiting your approval** |
| 1 Brand and design | Approved identity | Moodboard, 3 style frames, logo (5 routes → shortlist → final), tokens with contrast checks, type pairing, components, 3D style frames, hero animatic, homepage designs 360/1440 | Logo, palette, type, 3D, motion, design approved; quality bar passed |
| 2 Homepage MVP | Build approved design | All 14 sections + fallbacks, a11y, budgets met in prod build | Matches design, budgets pass |
| 3 Conversion, SEO, launch | Real enquiries | Backend for form, WhatsApp, spam protection, metadata, schema, consent analytics, Vercel + domain, privacy policy | Accepts genuine enquiries; launch checklist passes |
| 4 Demos | Portfolio | Clinic → gym → real-estate demos, each with own identity; labelled concept work | Review after each |
| 5 Reusable foundation | Shared components, token theming, industry configs, onboarding docs | New industry site via config |
| 6 CRM foundation | Auth, orgs, roles, contacts, leads, pipeline, tasks, tests for tenant isolation | Tested shared core |
| 7 Clinic CRM MVP | Smallest useful clinic workflow, no medical records | Clinic tracks enquiries end to end |
| 8 Gym, real-estate CRM | Separate modules on shared core | |
| 9 AI automation | One feature at a time with guardrails | |
